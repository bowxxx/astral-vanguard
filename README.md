ASTRAL VANGUARD is an endless horizontal space shooter / bullet-hell built with pure HTML5 Canvas 2D and WebAudio — no libraries, no network requests. One ship defends the Nyx crystal belt across endless sectors: crystal meteors that split apart, magma meteors, drone swarms, laser gates, and a three-phase cosmic boss at the end of every sector. Permanent relic upgrades between sectors, a screen-clearing Nova Beam, a dash with i-frames, combo and graze scoring, and a fully procedural soundtrack synthesized live in the browser.

## Run it

```sh
python3 -m http.server 8080 --directory game
# then open http://localhost:8080
```
